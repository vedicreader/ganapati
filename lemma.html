Lemmas, glosses, and the profiles that put them in a store

Lemmas

fold_token collides two spellings of a word. It cannot collide two forms: someone typing gam will not find gacchati. That needs a dictionary, which is what vidyut is, so it is opt-in.

Facets

lemma_facets drops any lemma the surface index already holds, meaning one whose fold_token matches the surface form.

A source may already carry the analysis. etym_facets reads the > etym: lines a reader wrote and splits them by script: a token with Devanagari or IAST diacritics is a lemma, a plain English word is a gloss. source_meta is metre plus timings plus that, and it is what sanskrit_meta(None) returns — no vidyut import, no 81 MB download. When a pipeline is supplied, the source’s own analysis still wins and vidyut is called only for the chunks that lack one.

lemma_facets

def lemma_facets(
    text:str, # chunk text
    nlp, # a `vidyut_pipe()` (or any spaCy-shaped pipeline)
    max_terms:int=96, # cap, so one chunk's metadata cannot outgrow its content
)->dict:

{'lemma': 'gam vac ...'} for a chunk — the dictionary forms behind its inflected words.

from ganapati.text import vr_xml_parse
VR = '''<lyrics><section name="anuvaka 1">
  <line ignore="true">॥ श्रीरुद्रचमकप्रश्नः ॥</line>
  <line start_time_ms="0" end_time_ms="1800"
        etymology="agni: fire, the god of fire; viṣṇu: voc. du., the all-pervader">अग्नाविष्णू सजोषसेमा</line>
</section></lyrics>'''

f = etym_facets(vr_xml_parse(VR)[0][-1][1])
assert f['lemma'] == 'agni viṣṇu'                        # the headword of each `word: gloss` entry
assert f['gloss'] == 'fire god all-pervader'             # and no grammar, no stopwords
assert sanskrit_meta() is source_meta                    # the cheap path, and no vidyut in it
assert source_meta(vr_xml_parse(VR)[0][-1][1])['mora_rate'] == '112'

Searching what was written

by_lemma and by_meter filter on the metadata the facets wrote. Filters, not rankings: they narrow, and hybrid search orders what is left.

Profiles

register_profiles() tells litesearch which extensions to try, how to sniff a shared one, which chunker, and what metadata to write. It runs on import. Call it again with nlp= and mw= to add lemmas and glosses to everything indexed after.

register_profiles

def register_profiles(
    nlp:NoneType=None, mw:dict=None
):

Register the Sanskrit profiles. Called on import; safe to call again.

from litesearch.data import profile_for
from litesearch import Index
import json, numpy as np
from fastcore.all import Path, first
gretil = "atha prathamo'dhyāyaḥ || MBh_1,1.1 ||\n" * 10
p = profile_for('mahabharata_u.htm', gretil)
assert p and p.name == 'sanskrit_verse'
assert p.chunker is VerseChunker and p.kind == 'sanskrit'

assert sanskrit_meta(None) is source_meta          # no pipeline, no vidyut import
# and it still carries the metre: a real verse in, its metre out
assert sanskrit_meta(None)('dharmakṣetre kurukṣetre samavetā yuyutsavaḥ '
                          'māmakāḥ pāṇḍavāścaiva kimakurvata sañjaya')['meter'] == 'anuṣṭubh'
assert sanskrit_meta(None)('') == {}
# the corpus's own shape: `surface, lemma, grammar…, gloss`, one entry per line
E = """> etym: गणानां, gaṇa, genitive case, masculine gender, plural number, of troops.
> etym: हवामहे, hvā, present tense, indicative mood, first person, plural number, we invoke.
> etym: विष्णुं, viṣṇu, case=accusative, gender=masculine, number=singular, Viṣṇu, the object of the meditation."""
f = etym_facets(E)
assert 'gaṇa' in f['lemma'] and 'hvā' in f['lemma'] and 'गणानां' in f['lemma']
# the grammar fields go to neither side: the lemma already implies them
assert 'troops' in f['gloss'] and 'invoke' in f['gloss']
assert not {'genitive', 'masculine', 'plural', 'accusative', 'tense', 'case'} & set(f['gloss'].split())

# the two other shapes a source may use still split
assert 'agnā' in etym_facets('> etym: agnā: agni, voc. du.')['lemma']
assert 'dharma' in etym_facets('> etym: The compound joins dharma with kshetra.')['gloss']
# the same lines read as records: surface, lemma, the grammar fields, the gloss
es = etym_entries('गणानां, gaṇa, genitive case, masculine gender, plural number, of troops.\n'
                  'विष्णुं, viṣṇu, case=accusative, gender=masculine, number=singular, Viṣṇu, the object of the meditation.\n'
                  'तत्, tad, nominal stem, form of the pronoun, that.\n'
                  '- agnā: agni, voc. du.')            # a `word: gloss` bullet is the other shape, not an entry
assert len(es) == 3
assert es[0].w == 'गणानां' and es[0].lemma == 'gaṇa' and es[0].gram == 'genitive case, masculine gender, plural number' and es[0].g == 'of troops.'
assert es[1].gram == 'case=accusative, gender=masculine, number=singular' and es[1].g == 'Viṣṇu, the object of the meditation.'
assert es[2].gram == 'nominal stem, form of the pronoun' and es[2].g == 'that.'   # a gloss with a comma in it stays whole
assert etym_entries('') == [] and etym_entries('just prose, with commas, in it') == []

A gloss that was written in the wrong script

An LLM asked for a Devanagari headword sometimes reads the English gloss as IAST and writes it in Devanagari too, so an ox; cattle becomes अन् ओक्ष्; चत्त्ले. delatinize reads such a line back. The reference is the corpus’s own vocabulary, gloss_vocab, so a word only counts as English when the corpus has glossed with it before; a well-formed entry and a real Sanskrit line are left alone. Reading back needs aksharamukha, which is not a dependency: the first call says so.

gloss_vocab

def gloss_vocab(
    texts
)->set:

The English words the corpus’s own parseable glosses use: the reference for spotting an entry that is not English at all.

v = gloss_vocab(['गणानां, gaṇa, genitive case, of troops.',
                 'गौः, go, nominative case, an ox; cattle; the earth.',
                 'सूर्यः, sūrya, nominative case, the sun; light of the sun.'])
assert v == {'an', 'cattle', 'earth', 'light', 'of', 'ox', 'sun', 'the', 'troops'}

bad = 'थे सुन्; लिघ्त् ओफ़् थे सुन्'                  # `the sun; light of the sun`, written as if it were IAST
assert latin_frac(bad, v) == (1.0, 6)
assert delatinize(bad, v) == 'the sun; light of the sun'

# left alone: real Sanskrit, a well-formed entry, a header, a `word: gloss` bullet
for s in ['गणानां त्वा गणपतिं हवामहे', 'गणानां, gaṇa, genitive case, of troops.', 'ॐ भूः', '- ॐ: Sacred syllable', '']:
    assert delatinize(s, v) == s
assert latin_frac('गणानां त्वा गणपतिं हवामहे', v) == (0.0, 4)

t, n = fix_etym(f'ॐ भूः\n{bad}\nगणानां, gaṇa, genitive case, of troops.', v)
assert n == 1 and t.splitlines()[1] == 'the sun; light of the sun' and t.splitlines()[0] == 'ॐ भूः'
# a real numbered HTML edition follows the same profile through Index.add.
# `mahabharata.htm` is GRETIL's Mahābhārata 1.1, 210 verses:

ix = Index()
assert ix.add(mbh) > 0
